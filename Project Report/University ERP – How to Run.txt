University ERP – How to Run

Requirements:
- Java 8 or above
- MySQL

Steps:
1. Import database:
   - Run schema.sql
   - Run sample_data.sql

2. Configure database in DBConnection.java:
   - URL
   - Username
   - Password

3. Run:
   - Open project in IntelliJ / Eclipse
   - Run Main.java
